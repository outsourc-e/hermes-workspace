## Safety contract

The router is local-only and does **not** connect:

- live Etsy upload/publish/edit/renew
- supplier messaging or purchases
- live Alura/AliExpress/Alibaba
- Google writes/OAuth
- ShotLab/paid generation
- browser automation
- new Hermes/Kanban/Codex workers
- uncontrolled worker fan-out

Route safety fields remain:

```text
localOnly:true
usageAllowed:false
workerSpawnAllowed:false
externalRequestsAllowed:false
liveActionsAllowed:false
```

## Meaning

This phase turns the Command Room Manager from a passive recommendation panel into a real local router:

```text
messy task → typed route → existing station/tool opens → local packet/workbench context appears
```

It still does **not** mean Hermes has full autonomous source-reading or live marketplace capability. The next safe phase is to route typed intents/events from Hermes into this same router without letting Hermes mutate UI/layout/assets directly.
