# War Room Olympus Command — Mythology / History Theme Correction Brief

Status: active guardrail for next asset-generation attempts.
Reason: DLV feedback — previous floor candidate had a nice vibe but was not connected enough to the intended mythology/history theme. It must not become live art.

## Direction
The War Room should feel like a living strategic chamber from mythological antiquity and historical command culture, upgraded subtly with Hermes/JARVIS signal energy — not a generic futuristic dashboard, neon sci-fi room, or SaaS command center.

## Required visual anchors
- Ancient Greek / Hellenistic command hall atmosphere.
- Mythological Olympus material language: dark marble, carved stone, bronze/antique gold inlay, temple geometry, subtle Greek key borders.
- Historical strategy-room feeling: campaign map table will come later as a separate prop; the floor base itself must remain empty.
- Hermes identity through subtle wing/caduceus/signal motifs only when abstract and non-textual; avoid logos or central emblems in the floor base.
- Serious, powerful, museum-quality / strategy-game environment art.

## Forbidden drift
- Generic JARVIS sci-fi room as the dominant theme.
- Dashboard walls, monitor banks, UI cards, hologram screens, buttons, labels, charts.
- Contact sheets or multi-panel output.
- People, gods, statues, busts, decorative figures, avatars, silhouettes.
- Central rug/sigil/emblem/furniture/table/stations in floor_base.
- Readable text, pseudo-text, glyph spam, shop/Etsy/business imagery.

## Floor base target
Create only an empty architectural shell:
- top-down or very shallow orthographic 16:9
- ancient Greek/Hellenistic stone floor + wall boundary
- open center and open future station zones
- premium mythology/history first, subtle cyan Hermes/JARVIS energy second
- enough negative space for later station layers

## Approval rule
Any candidate that is merely "cool futuristic command center" but not clearly mythology/history/Olympus must be rejected before registry approval.
