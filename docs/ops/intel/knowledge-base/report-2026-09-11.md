## 4. Opportunities spotted
* **The "Identity-First" Wedge:** Okta's focus on "Non-Human Identity" (NHI) for agents suggests a massive movement in the enterprise to manage agent permissions. We can position PrivacyScrubber as the *data-layer* for these NHIs.
* **MCP Gateway Commodity:** Both Prompt Security and TrueFoundry are leaning heavily into "MCP Gateway" terminology. We should ensure our roadmap explicitly references "MCP-compatible" sanitization to stay in this conversation.
* **Infrastructure-led Protection:** Protegrity's "AI Team Edition" (Python-pipeline-based) allows us to target the developer/MLOps persona specifically, alongside our current end-user/browser focus.
