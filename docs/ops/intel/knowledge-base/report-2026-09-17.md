# Product Intel Report — 2026-09-17 (deep cycle)

## 1. Executive summary
Today's deep cycle identified significant shifts in the agentic security landscape, specifically around the **Model Context Protocol (MCP)**. The emergence of the "MCP Top 10" and the "MCP Security Scanner" (Microsoft) highlights a transition from general LLM prompt injection risks to highly specific **tool-use/capability exploitation (MCP05, MCP09)**. Competitive activity remains high: **Nightfall** and **Straiker** are aggressively positioning around "MCP Gateway" and "Agent-SPM" capabilities, directly encroaching on our future agent-security roadmap. **TrueFoundry** remains a critical partner candidate for gateway-layer integration.

## 4. Opportunities spotted
* **The "MCP Security" Gap:** While competitors (Nightfall, Microsoft) are building "Gateways" to intercept tool calls, there is a massive gap in **Client-side/Edge-side protection** for the *user's prompt* before it ever hits the gateway. We can differentiate by offering "Privacy-Preserving Prompting" that complements a gateway's "Tool-Call Governance."
* **Agent-SPM as an entry point:** Moving beyond simple PII redaction to "Agent Security Posture" (e.g., checking if an agent's tool list contains high-risk/unverified MCP servers) could bridge the gap between PrivacyScrubber and Straiker's domain.
