# Browser Harness (Research Verification)

Use the **browser** toolset to verify external claims — not for open-ended browsing.

## When to use

- Confirm live product pages, docs, pricing, API behavior
- Capture screenshots or DOM snippets as evidence citations
- Cross-check researcher facts that `web` snippets cannot fully substantiate

## Discipline

1. State the claim being verified before navigating
2. Record exact URL, access date, and what was observed
3. Prefer primary sources (vendor docs, papers, official repos)
4. Close the loop — save citation in the mission artifact

## Do not

- Use browser for strategy synthesis or recommendation writing
- Leave long-running sessions open; one verification goal per navigation
