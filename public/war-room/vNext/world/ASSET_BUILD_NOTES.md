# Olympus vNext generated integration assets

Fallback asset pass built from existing premium War Room room scenes plus the approved layered Forge assets.

- `olympus-lego-realm-map.png`: responsive modular/interlocking realm map, text-free for HTML labels/hotspots.
- `/rooms/<room>/background.png`: per-room background layer.
- `/stations/<room>/<station>.png`: cropped image prop layers for every non-Forge station, with transparent feathered edges and ornate frame.

These are image assets, not CSS-drawn props. Replace individual PNGs later with ChatGPT-final transparent props without changing React manifest paths.
